# Deep Learning / NLP Text Classifier

## Project Overview
This project implements a Deep Learning-based Natural Language Processing (NLP) model for movie review sentiment analysis using TensorFlow and LSTM.

The model classifies movie reviews into Positive and Negative sentiments.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Natural Language Processing (NLP)
- Long Short-Term Memory (LSTM)

## Dataset
IMDB Movie Reviews Dataset.

- Training Samples: 25,000
- Testing Samples: 25,000
- Vocabulary Size: 10,000

## Model Architecture
1. Embedding Layer
2. LSTM Layer
3. Dropout Layer
4. Dense Layer
5. Sigmoid Output Layer

## Model Performance
- Test Accuracy: 84.76%
- Test Loss: 0.6473

## Features
- Text preprocessing
- Deep Learning model training
- Training and validation accuracy visualization
- Training and validation loss visualization
- Positive and Negative sentiment prediction
- Prediction confidence output

## Project Files
- `Deep_Learning_NLP_Text_Classifier.ipynb` – Complete project notebook
- `sentiment_model.keras` – Trained model
- `requirements.txt` – Required Python libraries

## How to Run
1. Open the Jupyter Notebook in Google Colab.
2. Run the notebook cells in order.
3. Train and evaluate the model.
4. Test new movie reviews.

## Sample Predictions
- "This movie is amazing and wonderful" – Positive
- "This movie is boring and terrible" – Negative
